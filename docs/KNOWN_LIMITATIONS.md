# Known Limitations

- The dataset is synthetic and deterministic.
- NusaTel Digital Network is fictional.
- The project does not contain real Telkom data, branding, or network information.
- There is no live NOC telemetry ingestion.
- There is no real-time streaming pipeline.
- There is no OSS/BSS, CRM, or ERP integration.
- Authentication is a local prototype using demo users and in-memory bearer tokens.
- There is no enterprise SSO.
- There is no cloud deployment in TOI-0002.
- Recommendations are rule-based and deterministic, not AI/ML predictions.
- The prototype is intended for portfolio and learning use, not production telecom operations.
