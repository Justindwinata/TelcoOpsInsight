# Maintenance Calendar

Unified operational calendar view for scheduled activities.

## Views

- **Monthly** - Full month grid with events
- **Weekly** - 7-day detailed view
- **Upcoming List** - Next 20 activities

## Event Types

- **Maintenance Jobs** - From maintenance schedule
- **Change Windows** - Approved change implementations
- **Site Maintenance** - Planned site activities

## API

`GET /api/calendar` - All calendar events with optional date filters
